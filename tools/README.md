# Tools

Helper scripts and test mods. Not shipped. Test mods run in an isolated `--mod-directory` (junctions to the mods under test, see CLAUDE.md "Headless test harness"), unless noted.

|------|------|--------|---------|

Headless on tick 2 → `script-output/map-check-result.txt`; in game `/ht-map-check`, `/ht-map-nearest` | Current. Junction `mods/ht-map-check` for debug runs (gitignored) | territory-brain B2, B3 |
| `ht-regrow-test/` | Regrowth: knocks pieces out of a base, `place_brain` in a water territory, runs `regrow` rounds. Needs `ht-map-check` (it generates the area) | Current headless regression test | territory-brain B5 |
| `ht-staging-test/` | Crusade staging next door: small generated area, one brain killed, `staging_for` | Current headless regression test | territory-brain B-I9 |

Average tick time with no challenge and during each swarm (`helpers.create_profiler`). Telemetry CSVs land in `script-output/ht-telemetry/`. Headless only (no players: drives waves against a player-less character), `--benchmark-ticks 7700`. → `script-output/e1-result.txt`, `e1-ups.txt` | Current headless regression test | challenge-feel E1-8, oil-ring E1-8 / OR-E2 |

Map gen also counts worms per base (OR-D105: none in rings 0–1). E8-B adds a speed check (queen and small biter on open ground and at the base), picks the ring-1 brain with the fewest cliffs + water, and logs queens every step (state, distance and angle from the target, command, escort distance, biters spawned), a killed queen's replacement, and no queens once all nests are dead; PT13 retreat: at 30 s the target jumps to 15 tiles from a queen; OR-E11: logs the queen level, kills a queen at 70 s and every nest at 100 s; OR-E12: the target is indestructible (no damage = calm, so the level climbs), smallest angle between the 4 queens, biters spawned while a queen walked; `--benchmark-ticks 7830`. BP-1 (balance pass): no queens in the siege, seconds from the wake to 4 queens, most units alive (cap 800). Can't test the siege start on an anchor hit (needs a player) | Current headless test | oil-ring E8-A |

**mod-list.json:** list every mod in the isolated mod directory, with `"enabled": false` for the ones not under test. Mods that aren't listed get enabled (2026-10-23: `ht-oil-ring-test` ran along and removed the ring-0 brains).

Headless runs without a server: `--create x.zip --map-gen-seed 12345`, then `--benchmark x.zip --benchmark-ticks N --benchmark-runs 1` (runs `control.lua`, exits by itself). Own `--config` with `write-data` in the scratchpad. Details: hive-layout-plan.md, step-by-step checklist.
